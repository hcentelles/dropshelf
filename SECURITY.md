# Report a security issue

Open the repository's **Security** tab and select **Report a vulnerability**. If that option is unavailable, open an issue asking a maintainer for a private contact. Share the technical details only through the private channel.

Include the affected commit or version, the impact, and steps to reproduce the problem in a local test instance. Remove access tokens, signed transfer links, private hostnames, and uploaded files from the report.

See the [security model](docs/security.md) for access rules, file handling, and the separate app and content origins.
